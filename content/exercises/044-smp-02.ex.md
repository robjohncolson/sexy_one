## Which button enters Sampling mode

type: quiz
id: q-3-13
cite: guide-book 29 "Press the `REC` button to enter Sampling mode"
tags: sampling, intro

From Performance mode, which button do you press to enter Sampling mode?

- [x] `REC`
- [ ] `EDIT`
- [ ] `DEL`
- [ ] `▶/■`

### Why

Each function button opens its own mode from Performance mode: `REC` enters Sampling
mode, `DEL` enters the deletion mode, and `EDIT` enters the editing mode -- `REC` is
the one that records.

## What the panel does when you enter Sampling mode

type: quiz
id: q-3-14
cite: guide-book 29 "empty pads flash"
tags: sampling, intro

The moment you enter Sampling mode, what happens on the panel?

- [x] The `REC` button flashes and the empty pads flash
- [ ] The `REC` button lights steadily and every pad lights white
- [ ] All pads go dark until you select one
- [ ] Only the display changes -- no lights change

### Why

The flashing is an invitation: the flashing `REC` button says the unit is armed but not
yet recording, and the flashing pads show you exactly which pads are free to record to.

## What the Sampling mode display shows

type: quiz
id: q-3-15
cite: guide-book 29 "SAMPLING MODE: AUTO TRIGGER"
tags: sampling, intro

Describe what the display shows once you are in Sampling mode.

### Answer

It reads `SAMPLING MODE` with the current trigger setting (for example
`AUTO TRIGGER`), plus L and R level meters.

### Why

Reading this screen is how you confirm which trigger will start the recording and
whether your input level is healthy -- both before you commit a sound to a pad.

## Changing the trigger setting

type: quiz
id: q-3-16
cite: guide-book 29 "Select it with the directional buttons"
tags: sampling, intro

In Sampling mode, which controls select the trigger setting?

- [x] The directional buttons `←`/`→`
- [ ] The two dials
- [ ] The `A`-`D` buttons
- [ ] Tapping any pad

### Why

The directional buttons `←`/`→` step through the trigger settings. The `A`-`D` buttons
choose banks, and tapping a pad in Sampling mode selects the recording target instead.

## What AUTO TRIGGER does

type: quiz
id: q-3-17
cite: guide-book 29 "starts recording automatically when sound is input"
tags: sampling, core

What does the `AUTO TRIGGER` setting do?

- [x] Starts recording automatically when sound is input
- [ ] Starts recording the moment you select a pad
- [ ] Starts recording on the next beat of `MASTER BPM`
- [ ] Records only while you hold the pad down

### Why

With `AUTO TRIGGER`, the unit waits silently after you select a pad and starts
recording the instant sound arrives -- so you never record dead air at the front of a
sample. Starting on pad selection is the other trigger's job.

## When MANUAL TRIGGER starts recording

type: quiz
id: q-3-18
cite: guide-book 29 "recording starts the moment you select a pad"
tags: sampling, core

With `MANUAL TRIGGER`, when does recording start -- and when would you choose it?

### Answer

Recording starts the moment you select a pad. Choose it when you want to decide the
sampling start timing yourself instead of letting the input sound trigger it.

### Why

`AUTO TRIGGER` waits for sound; `MANUAL TRIGGER` puts the start under your finger.
That control matters when the sound you are capturing has a quiet start that
`AUTO TRIGGER` might clip off, or when you want to start on a count.
