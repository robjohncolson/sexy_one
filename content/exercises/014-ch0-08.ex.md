## Which USB port supplies power

type: quiz
id: q-0-26
cite: guide-book 10 "USB port for power supply and for data communication with a smartphone"
tags: front-matter, core

This unit has two USB ports: DATA and POWER/DATA. Which of them can supply power to
this unit?

- [x] Only the POWER/DATA port
- [ ] Only the DATA port
- [ ] Both ports
- [ ] Neither — power comes only from batteries

### Why

Both ports handle data communication with a smartphone, but only POWER/DATA also
supplies power. That asymmetry is why the power precautions tell you to put the
adaptor on POWER/DATA and, if needed, the smartphone on DATA.

## The INPUT SELECT positions

type: quiz
id: q-0-28
cite: guide-book 10 "MIC: built-in microphone / ♪: AUDIO IN jack / USB: USB port"
tags: front-matter, core

The `INPUT SELECT` switch chooses the input used for recording. Map each of its three
positions — `MIC`, `♪`, and `USB` — to what it selects.

### Answer

`MIC` selects the built-in microphone, `♪` selects the AUDIO IN jack, and `USB`
selects the USB port.

### Why

Sampling always starts by pointing this switch at the right input — mic for the room,
`♪` for an external device on AUDIO IN, `USB` for digital audio over USB.

What is the built-in speaker for, and where on this unit does the five-view diagram
place it?

### Answer

It is used for playback with this unit on its own, and the diagram places it on the
rear.

### Why

Knowing the speaker fires from the rear explains why sound changes when this unit
lies flat on a soft surface — and why the speaker keeps playing even with LINE OUT
connected.

## Short press versus long press on A-D

type: quiz
id: q-0-37
cite: guide-book 11 "After long-pressing one of the `A`–`D` buttons"
tags: front-matter, core

From Performance mode, pressing a bank select button leads to two different selection
screens depending on how long you hold it. Which press leads where?

- [x] Short press: bank selection; long press: sequence selection
- [ ] Short press: sequence selection; long press: bank selection
- [ ] Short press: bank selection; long press: system settings
- [ ] Both lead to bank selection; only `EDIT` reaches sequences

### Why

Short-pressing an `A`-`D` button opens bank selection, where the directional buttons
choose the bank assigned to that button; long-pressing it opens sequence selection
instead. The system settings hang off `EDIT`, not the bank buttons.

## Three buttons, three modes

type: quiz
id: q-0-38
cite: guide-book 11 "Performance mode → REC mode: REC"
tags: front-matter, core

From Performance mode, which mode does each of `REC`, `DEL`, and `EDIT` enter?

### Answer

`REC` enters REC mode (sampling), `DEL` enters DEL mode (deleting sounds), and `EDIT`
enters EDIT mode (editing sounds).

### Why

The mode map is almost a mnemonic: each function button is the door to the mode named
after it. Only the system settings need something extra — a long press.

## EDIT short versus EDIT long

type: quiz
id: q-0-39
cite: guide-book 11 "long-press EDIT / EDIT"
tags: front-matter, core

From Performance mode, how do you open EDIT mode, and how do you open the system
settings?

- [x] Press `EDIT` for EDIT mode; long-press `EDIT` for the system settings
- [ ] Long-press `EDIT` for EDIT mode; press `EDIT` for the system settings
- [ ] Press `EDIT` for both; the directional buttons switch between them
- [ ] Press `DEL` for EDIT mode; press `EDIT` for the system settings

### Why

A short press of `EDIT` opens EDIT mode for the current pad's sound; a long press
opens the system settings, which affect this unit as a whole.
