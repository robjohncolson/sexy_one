# Getting ready to sample

deck: smp-01
chapter: Part: Sampling
tier: core
summary: Pick the right input source and set your levels before you record a single sound.
cite: guide-book 28 "Getting ready to start sampling"

Before you record anything, the SXC-1 needs to know where the sound is coming from --
the built-in microphone, the AUDIO IN jack, or a smartphone on the DATA port -- and the
input level has to be right. This deck covers the whole setup checklist.

## Spotting an empty pad

type: quiz

tags: sampling, core

In Performance mode, how do you recognize a pad that has no sample assigned to it?

- [x] It does not light up
- [ ] It flashes
- [ ] It lights up white
- [ ] It lights up yellow

### Why

Pads with no sample assigned do not light up. Flashing, white, and yellow all mean
something else -- empty pads flashing happens in Sampling mode, and yellow marks a pad
that just received a sample.

## Recording from the AUDIO IN jack

type: quiz
id: q-3-07
cite: guide-book 28 "To record an instrument performance or the like"
tags: sampling, core

An instrument is connected to the AUDIO IN (♪) jack. Where do you set the
`INPUT SELECT` switch to record it?

- [x] `♪`
- [ ] `MIC`
- [ ] `USB`

### Why

`INPUT SELECT` chooses the input source: `MIC` is the built-in microphone, `♪` is the
AUDIO IN jack, and `USB` is the DATA port -- match the switch to where the sound
actually enters this unit.

## Recording from a smartphone

type: quiz
id: q-3-08
cite: guide-book 28 "playback sound from a smartphone connected to the DATA port"
tags: sampling, core

A smartphone is connected to the DATA port and you want to record its playback sound.
Where do you set the `INPUT SELECT` switch?

- [x] `USB`
- [ ] `♪`
- [ ] `MIC`

### Why

The DATA port is a USB connection, so the switch goes to `USB`. The `♪` position is for
the AUDIO IN jack, and `MIC` would record the room through the built-in microphone
instead of the smartphone's playback.

## Setting INPUT VOL for the microphone

type: quiz
id: q-3-09
cite: guide-book 28 "Set INPUT VOL to maximum"
tags: sampling, core

When sampling with the built-in microphone, where does the Guide Book tell you to set
`INPUT VOL`?

- [x] Maximum
- [ ] Minimum
- [ ] Exactly halfway
- [ ] Wherever the level meter stops moving

### Why

For the built-in microphone, `INPUT VOL` goes to maximum -- your voice is a quiet
source compared with a line-level device. When recording from an external device you
balance levels against the meter instead.

## Keeping the level meter out of trouble

type: quiz
id: q-3-11
cite: guide-book 28 "does not peak out (swing all the way) while recording"
tags: sampling, core

While recording from a connected device, what should you watch on the display, and
which two volume controls do you adjust for it?

### Answer

Watch the level meter: adjust the connected device's volume and this unit's
`INPUT VOL` so the meter does not peak out (swing all the way) while recording.

### Why

A peaked-out meter means the input is clipping, and the distortion gets baked into the
sample -- no amount of editing afterwards can un-clip it.
