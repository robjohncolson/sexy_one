## Clear sounds in bulk
ja: ## 音をまとめて削除する

type: drill
id: d-4-11
cite: guide-book 44 "Lets you delete sounds in bulk"
tags: sequencer, stretch

On a pattern you can afford to lose, run all three CLEAR scopes and watch exactly
how much each one erases. Every execution asks for confirmation first.
ja: 消えても困らないパターンを使って、CLEAR の3つの範囲をすべて実行し、それぞれどこまで
ja: 消えるのかを目で確かめましょう。実行の前には必ず確認画面が表示されます。

### Step

cite: guide-book 44 "Deletes one measure's worth of the sound of the pad where the cursor is placed"
check: A confirmation display appears before anything happens; after OK, only that pad's cells in that measure empty -- the other rows stay filled.
ja: check: 何かが変わる前に確認画面が表示され、OK のあとはその小節のそのパッドのマスだけが空になり、ほかの行は埋まったまま残る。

Place the cursor on a filled cell, then press `EDIT`, select CLEAR, choose `TRACK`
with ←/→, and press `A`; on the confirmation display press `A` again to execute.
ja: 音の入っているマスにカーソルを置き、`EDIT` を押して CLEAR を選び、←/→ で `TRACK` を
ja: 選んで `A` を押します。確認画面でもう一度 `A` を押すと実行されます。

### Step

cite: guide-book 44 "Deletes all the sounds in the measure where the cursor is placed"
check: After the confirmation, every row of that measure is empty, while other measures keep their sounds.
ja: check: 確認のあと、その小節はすべての行が空になり、ほかの小節の音はそのまま残っている。

Return to the grid, place the cursor in a measure that still has sounds, and run
CLEAR again with the `BAR` scope.
ja: マス目の画面に戻り、まだ音が残っている小節にカーソルを置いて、今度は `BAR` の範囲で
ja: CLEAR を実行します。

### Step

cite: guide-book 44 "Deletes all the sounds in the currently selected sequence"
check: The display asks `CLEAR ALL?  OK(A)  CANCEL(B)`; after OK, the entire grid is empty in every measure.
ja: check: 画面に `CLEAR ALL?  OK(A)  CANCEL(B)` と表示され、OK のあとはすべての小節でマス目が空になる。

Finally, run CLEAR with the `ALL` scope. Try pressing `B` once at the confirmation
to see the cancel path, then execute with `A`.
ja: 最後に `ALL` の範囲で CLEAR を実行します。確認画面で一度 `B` を押してキャンセルの動きを
ja: 確かめてから、`A` で実行しましょう。

## Where the sequencer came from
ja: ## シーケンサーの成り立ち

type: quiz
id: q-4-54
cite: guide-book 45 "existed as a standalone piece of hardware"
tags: sequencer, intro

How has the sequencer changed as a piece of music technology?
ja: 音楽の道具として、シーケンサーはどのように変わってきましたか。

- [x] It was once standalone hardware; today it is a function built into DAWs and gear like the SXC-1
ja: - [x] 昔は単体のハードウェア機材だったが、現在は DAW や SXC-1 のような機材に搭載される機能の1つになった
- [ ] It began as software and only recently became hardware
ja: - [ ] ソフトウェアとして生まれ、最近になってハードウェアになった
- [ ] It has always been a DAW-only feature
ja: - [ ] 昔からずっと DAW だけの機能である
- [ ] It was invented for the SXC-1
ja: - [ ] SXC-1 のために発明された

### Why

Knowing the sequencer is one function among many explains this unit's design: it is
pared down to the basics on purpose, so first-timers can write music without getting
stuck.
ja: シーケンサーが数ある機能の1つだと分かると、本機の設計の意図も見えてきます。あえてごく
ja: 基本的な機能に絞ってあるので、初めての人でも悩まずに曲作りを楽しめるのです。

## Where to start a song
ja: ## 曲はどこから作り始めるか

type: quiz
id: q-4-55
cite: guide-book 45 "Starting from a rhythm pattern is fine"
tags: sequencer, intro

According to the CREATIVE NOTE, where should you start when building a song?
ja: CREATIVE NOTE によると、曲作りはどこから始めればよいとされていますか。

### Answer

Anywhere that works for you: starting from a rhythm pattern is fine, and so is a
chord progression that feels good, or a melody that suddenly comes to you.
ja: やりやすい方法ならどこからでも構いません。リズムパターンから作るも良し、気持ちいいコード
ja: 進行や、ふと閃いたメロディから始めるも良しです。

## Getting looped sounds into the mix
ja: ## ループ音源を曲に取り込む

type: quiz
id: q-4-41
cite: guide-book 43 "it is possible to layer looped sounds by performing in real time"
tags: sequencer, core

Looped sounds cannot be incorporated into a sequence. How do you use them with one
anyway?
ja: ループ音源はシーケンスに組み込めません。それでもシーケンスと一緒に使うには、どうすれば
ja: よいですか。

- [x] Layer them by performing in real time while the sequence plays back
ja: - [x] シーケンスを再生しながらリアルタイム演奏する形で重ねる
- [ ] Convert them to one-shot sounds first
ja: - [ ] 先にワンショット音源に変換しておく
- [ ] Put them in a second sequence and play both
ja: - [ ] もう1つのシーケンスに入れて、2つを同時に再生する
- [ ] Shorten them to a single 16th note
ja: - [ ] 16分音符1つ分の長さまで短くする

### Why

The sequence handles the one-shot backbone; your hands add the loops live on top --
a technique the book's final part builds a whole page around.
ja: 土台となるワンショット音源はシーケンスに任せ、その上にループ音源を自分の手でその場で
ja: 重ねます。この手法には、ガイドブックの最終 PART で1ページが割かれています。

## Managing fifty sequence banks
ja: ## 50個のシーケンスバンクを管理する

type: quiz
id: q-4-13
cite: guide-book 36 "Sequence banks are easy to manage using the dedicated app"
tags: sequencer, intro

You will eventually have dozens of sequence banks. What does the manual recommend
for managing them easily?
ja: シーケンスバンクは、いずれ何十個にもなります。ガイドブックは、それらを簡単に管理する
ja: 方法として何をすすめていますか。

- [x] Use the dedicated app
ja: - [x] 専用アプリを使う
- [ ] Reassign the `A`-`D` buttons on the unit
ja: - [ ] 本機の `A`～`D` ボタンを割り当て直す
- [ ] Keep a written list of bank numbers
ja: - [ ] バンク番号の一覧を紙に書いておく
- [ ] Delete old sequences as you go
ja: - [ ] 古いシーケンスをこまめに削除する

### Why

The unit can only show one bank number at a time at sequence selection; the app can
list and organize all fifty, which is why the manual points bank management there.
ja: 本機のシーケンス選択表示では、バンク番号を一度に1つしか確認できません。専用アプリなら
ja: 50個すべてを一覧して整理できるため、ガイドブックはバンクの管理をアプリにゆだねています。
