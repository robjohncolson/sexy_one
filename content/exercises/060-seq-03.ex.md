## The bank area
ja: ## バンクのエリア

type: quiz
id: q-4-14
cite: guide-book 37 "Shows which of the bank select buttons `A`–`D` is selected"
tags: sequencer, intro

What does the bank area of the Sequence mode display show?
ja: シーケンスモード表示のバンクのエリアには、何が表示されますか。

- [x] Which bank select button `A`-`D` is selected -- that is, which sound bank will be played
ja: - [x] バンク選択ボタン `A`～`D` のどれを選んだか、つまりどの音色バンクを鳴らすのか
- [ ] Which sequence bank number the pattern is saved in
ja: - [ ] パターンがどのシーケンスバンク番号に保存されているか
- [ ] How many banks contain samples
ja: - [ ] サンプルの入ったバンクがいくつあるか
- [ ] Which pad was tapped last
ja: - [ ] 最後に叩いたパッドはどれか

### Why

The display's bank area is about the *sound* bank feeding the sequence -- the
sequence bank you chose at selection time is a different thing, and the display does
not restate it here.
ja: バンクのエリアが示すのは、シーケンスで鳴らす「音色バンク」です。シーケンス選択のときに選んだ
ja: シーケンスバンクは別物で、この場所には表示されません。

## Seeing pads 7 and beyond
ja: ## パッド7以降を表示する

type: quiz
id: q-4-18
cite: guide-book 37 "For pad 7 and beyond, scroll with the directional buttons"
tags: sequencer, core

The grid only shows a few pad rows at a time. How do you display pad 7 and beyond?
ja: 画面に一度に表示されるパッドの行は一部だけです。パッド7以降を表示するには、どう操作しますか。

- [x] Scroll with the directional buttons
ja: - [x] 十字ボタンでスクロールして表示する
- [ ] Tap the pad you want to see
ja: - [ ] 表示したいパッドを叩く
- [ ] Press the `EDIT` button

ja: 画面に収まるのはパッド6行分ですが、パターンには16個すべてのパッドを使えます。
ja: 残りのパッドは十字ボタンのスクロールで表示します。

## The pad input area
ja: ## パッド入力のエリア

type: quiz
id: q-4-19
cite: guide-book 37 "Divides 1 measure into 16 parts and shows which pad's sample will sound at which timing"
tags: sequencer, core

How does the pad input area represent one measure of your pattern?
ja: パッド入力のエリアは、パターンの1小節をどのように表しますか。

- [x] It divides 1 measure into 16 parts and shows which pad's sample sounds at which timing
ja: - [x] 1小節を16分割し、どのパッドのサンプルをどのタイミングで鳴らすかを示す
- [ ] It divides 1 measure into 8 parts, one per beat
ja: - [ ] 1小節を8分割し、1拍に1マスずつ割り当てて示す
- [ ] It shows one column per pad and one row per measure
ja: - [ ] パッドごとに1列、小節ごとに1行で示す
- [ ] It draws the waveform of each sample
ja: - [ ] 各サンプルの波形を描いて示す

### Why

Sixteen parts per measure is not an arbitrary display choice -- it matches the
sequencer's smallest timing unit, the 16th note, which you will meet as "quantize".
ja: 1小節を16分割するのは、見た目の都合ではありません。シーケンスモードで扱う音の最小単位である
ja: 「16分音符」に対応していて、のちに「クォンタイズ」として登場します。

## Setting the number of measures
ja: ## 小節数を決める

type: quiz
id: q-4-21
cite: guide-book 38 "move the ▲ below the numbers to 2, then press the `A` button"
tags: sequencer, core

The cursor is on the measure-number row. How do you set the pattern length to 2
measures?
ja: カーソルは小節数の行にあります。パターンの長さを2小節にするには、どう操作しますか。

- [x] Move the ▲ below the numbers to 2 with the right directional button, then press `A`
ja: - [x] 十字ボタンの右で数字の下の ▲ を2に移動させ、`A` ボタンを押す
- [ ] Move the ▲ to 2, then press `B`
ja: - [ ] ▲ を2に移動させ、`B` ボタンを押す
- [ ] Tap pad 2
ja: - [ ] パッド2を叩く
- [ ] Press the `A` button twice
ja: - [ ] `A` ボタンを2回押す

### Why

The ▲ marker picks the candidate length, but nothing changes until `A` confirms it --
the same choose-then-confirm rhythm the unit uses at sequence selection.
ja: ▲ は長さの候補を選ぶだけで、`A` を押して決定するまでは何も変わりません。シーケンス選択と同じ、
ja: 「選んでから決定する」という本機に共通した操作の流れです。

## Making a pattern shorter
ja: ## パターンを短くする

type: quiz
id: q-4-22
cite: guide-book 38 "Pressing the `B` button also lets you"
tags: sequencer, core

While setting the number of measures, what does pressing the `B` button let you do?
ja: 小節数を決めているとき、`B` ボタンを押すと何ができますか。

- [x] Reduce the number of measures
ja: - [x] 小節数を減らす
- [ ] Cancel and leave Sequence mode
ja: - [ ] キャンセルしてシーケンスモードから出る
- [ ] Erase the whole pattern
ja: - [ ] パターン全体を消す
- [ ] Double the number of measures
ja: - [ ] 小節数を2倍にする

### Why

`B` is not always "cancel": on the measure row it is the shrink direction, the
counterpart to growing the pattern with the ▲ and `A`.
ja: `B` はいつでも「キャンセル」とは限りません。小節数の行では減らす方向のボタンで、
ja: ▲ と `A` で増やす操作と対になっています。

## Set the number of measures to 2
ja: ## 小節数を2に設定する

type: drill
id: d-4-03
cite: guide-book 38 "move the ▲ below the numbers to 2, then press the `A` button"
tags: sequencer, core

In Sequence mode, prepare a 2-measure pattern by moving the cursor to the measure
row and confirming a length of 2.
ja: シーケンスモードで、カーソルを小節数の行に移動して長さ2を決定し、2小節のパターンを準備しましょう。

### Step

cite: guide-book 38 "Press the up directional button and the cursor moves"
check: The cursor sits on the measure-number row at the top of the grid.
ja: check: カーソルが、マス目の上にある小節数の行に乗っている。

Press the up directional button until the cursor moves onto the measure-number row.
ja: カーソルが小節数の行に乗るまで、十字ボタンの上を押します。

### Step

cite: guide-book 38 "move the ▲ below the numbers to 2, then press the `A` button"
check: The measure indicator changes from showing measure 1 alone to showing measures 1 and 2.
ja: check: 小節数の表示が、1小節目だけの状態から、1小節目と2小節目を示す状態に変わる。

With the right directional button, move the ▲ below the numbers to 2, then press the
`A` button.
ja: 十字ボタンの右で、数字の下の ▲ を2に移動させ、`A` ボタンを押します。

### Step

cite: guide-book 38 "Then return to 1 for now with the left directional button"
check: The ▲ sits under 1 again while the indicator still shows a 2-measure pattern.
ja: check: ▲ が再び1の下にあり、表示は2小節のパターンのままになっている。

Return the ▲ to 1 for now with the left directional button. If you like, press `B`
once to watch the measure count reduce, then set it back to 2.
ja: 十字ボタンの左で、▲ を一旦1に戻します。よければ `B` ボタンを一度押して小節数が減るのを確かめ、
ja: また2に戻してみましょう。
