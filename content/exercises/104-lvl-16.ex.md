## The SXC-1's native sampling format
ja: ## SXC-1本体のサンプリング形式

type: quiz
id: q-5-93
cite: guide-book 66 "Recording format: WAV (stereo)"
tags: leveling-up, core, sample-lab

Which combination matches the SXC-1's documented sampling specification?
ja: SXC-1の製品仕様に記載されたサンプリング形式はどれですか。

- [x] Stereo WAV, 48 kHz, 16-bit linear PCM
ja: - [x] ステレオWAV、48 kHz、16ビットリニアPCM
- [ ] Mono MP3, 44.1 kHz, 16-bit
ja: - [ ] モノラルMP3、44.1 kHz、16ビット
- [ ] Stereo FLAC, 96 kHz, 24-bit
ja: - [ ] ステレオFLAC、96 kHz、24ビット
- [ ] `.cswp`, with no fixed sample rate
ja: - [ ] サンプルレートが固定されない`.cswp`

### Why

The product specification names all four parts together: 16-bit linear,
48 kHz, WAV, and stereo. Sound Check treats that exact combination as the
ready target while preserving other supported files unchanged.
ja: 製品仕様には、16ビットリニア、48 kHz、WAV、ステレオの4点がまとめて記載されています。
ja: サウンドチェックはこの組み合わせを準備完了の目標にし、それ以外の対応ファイルも変更せず保持します。

## The recording limit
ja: ## 録音時間の上限

type: quiz
id: q-5-94
cite: guide-book 66 "Recording time: up to 15 minutes (approx. 173 MB)"
tags: leveling-up, core, sample-lab

What maximum recording length and approximate size does the specification give
for one SXC-1 sample?
ja: SXC-1のサンプル1つについて、製品仕様に記載された録音時間と容量の上限はどれですか。

- [x] Up to 15 minutes, approximately 173 MB
ja: - [x] 最大15分、約173 MB
- [ ] Up to 5 minutes, approximately 48 MB
ja: - [ ] 最大5分、約48 MB
- [ ] Up to 30 minutes, approximately 346 MB
ja: - [ ] 最大30分、約346 MB
- [ ] There is no per-sample limit
ja: - [ ] サンプルごとの上限はない

### Why

The 48 MB boundary in Sound Check is only the app's local threshold for a deep
PCM scan; it is not the sampler's recording limit. The SXC-1 specification is
15 minutes and approximately 173 MB.
ja: サウンドチェックの48 MBは、アプリがPCMを詳しく走査するための端末内の境界であり、本機の録音上限ではありません。
ja: SXC-1の仕様は最大15分、約173 MBです。

## Supported is not the same as native
ja: ## 「対応形式」と「本機の形式」は同じではない

type: quiz
id: q-5-95
cite: guide-book 57 "WAV, MP3, and FLAC sound files or .cswp files can be used"
cite: guide-book 66 "Recording format: WAV (stereo)"
tags: leveling-up, core, sample-lab

CASIO Sampler App can assign an MP3 file. Why can Sound Check still recommend
exporting a stereo 48 kHz / 16-bit PCM WAV from Audacity?
ja: CASIO Sampler AppではMP3を登録できます。それでもサウンドチェックがAudacityからステレオ48 kHz／16ビットPCM WAVで書き出すよう勧めるのはなぜですか。

- [x] MP3 is accepted for assignment, while that WAV combination matches the unit's own documented sampling format
ja: - [x] MP3は登録に対応し、そのWAV形式は本機自身のサンプリング仕様に一致するから
- [ ] MP3 files are rejected by CASIO Sampler App
ja: - [ ] CASIO Sampler AppはMP3を受け付けないから
- [ ] WAV always makes a sample louder
ja: - [ ] WAVにすると必ず音量が上がるから
- [ ] The SXC-1 can play only files created by Audacity
ja: - [ ] SXC-1はAudacityで作ったファイルしか再生できないから

### Why

The app's import list describes compatibility; the product specification
describes the unit's native recording. Sample Lab keeps both truths visible:
supported files can travel, and the native WAV target receives a ready verdict.
ja: アプリの読み込み一覧は互換性を示し、製品仕様は本機自身の録音形式を示します。
ja: Sample Labは両方を区別して表示します。対応ファイルは引き渡すことができ、本機のWAV形式なら準備完了になります。
