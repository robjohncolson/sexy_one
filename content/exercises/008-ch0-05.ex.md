## Batteries in, adaptor connected: which wins?

type: quiz
id: q-0-34
cite: guide-book 8 "USB power takes priority"
tags: front-matter, core

Four batteries are installed, and a USB AC adaptor is also connected to the
POWER/DATA port. Which power supply does this unit run on?

- [x] USB power — it takes priority over the batteries
- [ ] The batteries — installed batteries always take priority
- [ ] Whichever was connected first
- [ ] Neither; this unit refuses to power on until one is removed

### Why

When a USB AC adaptor is connected to the POWER/DATA port while batteries are
installed, USB power takes priority. That is why leaving batteries in as a fallback
is safe — but also why a loose USB cable can still cut the power mid-recording, so
keep the cable securely connected.

## LINE OUT is connected — is the speaker quiet?

type: quiz
id: q-0-35
cite: guide-book 8 "sound is still output from this unit's speaker"
tags: front-matter, core

You connect an external speaker to the LINE OUT jack. What happens to this unit's own
built-in speaker, and how do you silence it if you want only the external speaker?

### Answer

Sound is still output from this unit's speaker — connecting LINE OUT does not mute
it. To silence this unit's speaker, set MAIN VOL to minimum.

### Why

LINE OUT and the built-in speaker are independent outputs, so the mix you hear in the
room is both at once unless you pull MAIN VOL down. (Headphones in the PHONE jack are
the opposite case — they do take over from the speaker.)
