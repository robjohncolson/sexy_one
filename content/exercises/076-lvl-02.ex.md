## The note number for pad 1, Bank A
ja: ## Bank Aのパッド1のノートナンバー

type: quiz
id: q-5-91
cite: midi 4 "Note mapping"
tags: midi, stretch

Which MIDI note number triggers pad 1 of Bank A, and where do the other banks
start?
ja: Bank Aのパッド1を鳴らすMIDIノートナンバーはどれですか。また、ほかのバンクはどの番号から始まりますか。

- [x] Note 36; each bank starts 16 higher (A at 36, B at 52, C at 68, D at 84)
ja: - [x] ノートナンバー36。各バンクの開始位置は16ずつ上がる（Aは36、Bは52、Cは68、Dは84）
- [ ] Note 0; each bank spans 32 consecutive notes
ja: - [ ] ノートナンバー0。各バンクが連続する32ノートを使う
- [ ] Note 60; banks share one range of 16 notes
ja: - [ ] ノートナンバー60。全バンクが1つの16ノートの範囲を共有する
- [ ] Note 36; all four banks respond to the same 16 notes
ja: - [ ] ノートナンバー36。4つのバンクすべてが同じ16ノートに反応する

### Why

One note per pad, sixteen pads per bank, with each bank's pad 1 starting 16
above the last -- that is the 36-99 transmit range. Banks A, B and D run
consecutively (36-51, 52-67, 84-99). Bank C's printed column, however,
contains a documented misprint in the original manual: pad 2 is listed as 68
again (duplicating pad 1) and note 69 never appears -- this translation
preserves the table exactly as printed. If you address Bank C pad 2 from a
sequencer, verify the real note number against your hardware.
ja: パッド1つにつきノート1つ、1バンクは16パッド、各バンクのパッド1は1つ前のバンクより16上 -- これが送信するノートナンバーの範囲36～99です。
ja: Bank A・B・Dは連続しています（36～51、52～67、84～99）。
ja: ただしBank Cの列にはマニュアル原本に誤植があり、パッド2がパッド1と同じ68と重複して記載され、ノートナンバー69はどこにも現れません。本コースの表もマニュアルの記載どおりに掲載しています。
ja: シーケンサーからBank Cのパッド2を指定する場合は、実際のノートナンバーを実機で確認してください。

## The receive-only note numbers
ja: ## 受信のみのノートナンバー

type: quiz
id: q-5-92
cite: midi 4 "these behave the same as pressing the current pad"
tags: midi, stretch

Note numbers 100-115 are receive-only. What happens when the unit receives one?
ja: ノートナンバー100～115は受信のみです。本機がこれらのノートを受信すると、どうなりますか。

### Answer

distractor: They select banks A-D by note range and work only in Performance mode.
ja: distractor: ノート範囲でバンクA～Dを選び、演奏モードでだけ動作する。

It triggers pads 1-16 of the *current* bank, regardless of which bank is selected
or what mode the unit is in -- for example, note 100 acts like pressing pad 1.
ja: バンクや本体のモードに関わらず、「現在の」バンクのパッド1～16を押した時と同じ動作をします。
ja: 例えば、ノートナンバー100を受信するとパッド1を押した時と同じです。

## Starting sequence playback for layering
ja: ## 重ね演奏のためにシーケンス再生をスタートする

type: quiz
id: q-5-01
cite: guide-book 47 "and sequence playback starts"
tags: leveling-up, core

You want a sequence to play while you tap pads over it. How do you start the
sequence?
ja: シーケンスを再生しながら、その上でパッドを叩きたいとします。シーケンスの再生はどうやってスタートしますか。

- [x] Press the `A`-`D` button holding the sequence bank together with the `▶/■` button
ja: - [x] 鳴らしたいシーケンスバンクが登録された `A`～`D` ボタンと `▶/■` ボタンを同時に押す
- [ ] Press the `▶/■` button alone
ja: - [ ] `▶/■` ボタンだけを押す
- [ ] Long-press the `EDIT` button
ja: - [ ] `EDIT` ボタンを長押しする
- [ ] Press the `REC` button
ja: - [ ] `REC` ボタンを押す

### Why

The button pair does both jobs at once: the `A`-`D` button picks *which* sequence
bank, and `▶/■` starts it -- leaving your hands free for the pads.
ja: この同時押しは2つの役割を一度にこなします。`A`～`D` ボタンで「どの」シーケンスバンクかを選び、`▶/■` で再生がスタートします。
ja: 両手はそのままパッド演奏に使えます。

## Loops that follow the sequence tempo
ja: ## シーケンスのテンポに合わせて鳴るループ

type: quiz
id: q-5-05
cite: guide-book 47 "the sample automatically plays in time with the tempo of the sequence"
tags: leveling-up, stretch

Beat Sync is ON. A sequence is already playing, and you trigger a loop sample that
has a BPM set. What happens to the loop?
ja: Beat SyncをONにした状態でシーケンスを再生中、BPMが設定されたループのサンプルを鳴らしました。ループはどうなりますか。

### Answer

distractor: The loop keeps its own recorded speed and ignores sequence tempo.
ja: distractor: ループは録音時の速さを保ち、シーケンスのテンポには従わない。

The sample automatically plays in time with the tempo of the sequence -- the loop
locks to the sequence's beat instead of its own recorded speed.
ja: サンプルは自動でシーケンスのテンポに合わせて鳴ります。
ja: ループは録音されたときの速さではなく、シーケンスのビートにシンクロします。
