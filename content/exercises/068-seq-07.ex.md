## The app's sequence toolbar

type: quiz
id: q-4-39
cite: guide-book 42 "Cut / Copy / Paste / Duplicate to next measure / Clear"
tags: sequencer, core

The CASIO Sampler App's sequence screen has an edit toolbar the unit itself lacks.
Which operations does it offer?

- [x] Cut / Copy / Paste / Duplicate to next measure / Clear
- [ ] Undo / Redo / Save / Load / Export
- [ ] Quantize / Swing / Humanize / Transpose / Mute
- [ ] Record / Play / Stop / Loop / Metronome

### Why

Repeating measures on the unit means re-entering them; the app's toolbar turns that
into a copy-paste, which is why the manual keeps pointing pattern-heavy work at the
app.

## Extend to 4 measures and add synth chords

type: drill
id: d-4-08
cite: guide-book 43 "use real-time input to enter the synth chords of pads `5`, `6`, `7`, and `8`"
tags: sequencer, stretch

Grow your 2-measure drum pattern into a 4-measure piece with a synth chord at the
top of every measure.

### Step

cite: guide-book 42 "change the number of measures to 4 measures"
check: The measure indicator changes from showing measures 1-2 to showing measures 1-4.

On the measure-number row, change the number of measures to 4, the same way you set
it to 2 before.

### Step

cite: guide-book 42 "input the same drum pattern as measures 1–2 into measures 3–4 as well"
check: Measures 3-4 show the same white-cell pattern as measures 1-2, and the loop plays drums through all four measures.

Press the `REC` button and input the same drum pattern into measures 3-4 as well.
(Step input while stopped works too.)

### Step

cite: guide-book 43 "use real-time input to enter the synth chords of pads `5`, `6`, `7`, and `8`"
verify: pad 5 bank A
check: Each measure shows one chord cell at its start, and playback is drums plus a chord change every measure.

While listening to the drum pattern, use real-time input to enter the synth chords
of pads `5`, `6`, `7`, and `8` -- one at the top of each measure, in order.

## What kinds of sounds go into a sequence

type: quiz
id: q-4-40
cite: guide-book 43 "Only one-shot sounds can be incorporated into a sequence"
tags: sequencer, core

Which sounds can be incorporated into a sequence?

- [x] Only one-shot sounds
- [ ] Only looped sounds
- [ ] Both one-shot and looped sounds
- [ ] Only sounds from BANK1

### Why

A looped sound never ends on its own, so it cannot sit in a 16th-note cell. The
workaround is to perform looped sounds live over the playing sequence instead.

## Reading the LEDs: practicing vs. inputting

type: quiz
id: q-4-42
cite: guide-book 43 "practice for a while with the sequence playing"
tags: sequencer, core

You are playing along with a sequence to rehearse before recording. What do the
`▶/■` and `REC` LEDs show while practicing, and what changes once you are actually
inputting?

### Answer

Practicing: `▶/■` flashing, `REC` lit. Inputting: both flashing. Pressing `REC`
during playback is what switches you from one to the other.

## Practice before inputting

type: drill
id: d-4-09
cite: guide-book 43 "practice for a while with the sequence playing"
tags: sequencer, core

Rehearse a new part over the playing sequence without recording a note, then commit
it only when it feels right.

### Step

cite: guide-book 43 "practice for a while with the sequence playing"
check: Your taps sound over the loop but no new cells fill in; `▶/■` flashes while `REC` stays lit.

Play the sequence with `▶/■` and practice your new part on the pads for a while.

### Step

cite: guide-book 43 "press the `REC` button to start inputting"
check: Both buttons flash, and from now on your taps fill in cells at their timings.

When the part feels solid, press the `REC` button to start inputting.
