## Why MAIN VOL goes to minimum first

type: quiz
id: q-0-31
cite: guide-book 7 "The MAIN VOL of this unit is shared between the headphones and the speaker."
tags: front-matter, core

Before turning the power on or connecting headphones, you should set MAIN VOL to
minimum and then raise it gradually. Why?

- [x] MAIN VOL is shared between the headphones and the speaker, and the actual volume differs between them at the same slider position
- [ ] The power switch does not work unless MAIN VOL is at minimum
- [ ] MAIN VOL also controls the input level for recording
- [ ] The speaker is muted whenever headphones are connected, so the slider has no effect

### Why

Because one slider serves two outputs whose loudness differs at the same position, a
level that was comfortable on the speaker can be painfully loud the moment headphones
go in. Starting from minimum and raising gradually protects your hearing — be
especially careful when switching from the speaker to headphones.

## Using the built-in microphone well

type: quiz
id: q-0-32
cite: guide-book 7 "designed for close-range sound pickup"
tags: front-matter, core

The built-in microphone has a design constraint that dictates how you position
whatever you are recording — and one recommended habit before any important
recording. Name both.

### Answer

It is designed for close-range sound pickup, so keep whatever you are recording close
to the mic. Before an important recording, make a test recording first to check the
distance to the mic and the surrounding noise.

### Why

A close-range mic simply cannot capture distant material well — no setting fixes
that. The test recording catches distance and noise problems while they are still
cheap to fix.

## The display went dark after half an hour

type: quiz
id: q-0-33
cite: guide-book 7 "If no operation is performed for about 30 minutes, the display turns off automatically."
tags: front-matter, core

You leave this unit powered on and untouched. After about 30 minutes the display goes
dark, but a single button or pad operation brings it right back. Which feature did
you just see?

- [x] The screen saver function
- [ ] The Auto Power Off function
- [ ] A depleted battery shutting the power off
- [ ] The display brightness setting stepping down

### Why

The screen saver exists to prevent display burn-in: after about 30 minutes without
operation it turns only the display off, and any button or pad operation restores it.
The manual stresses that this is different from the Auto Power Off function, which
turns the whole unit's power off.
