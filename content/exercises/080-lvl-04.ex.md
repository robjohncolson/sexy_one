## Group two pads so they cut each other off

type: drill
id: d-5-06
cite: guide-book 48 "pads with the same number are grouped"
tags: leveling-up, core

Make two long or looped sounds interrupt each other by grouping them, then undo it
and hear the difference.

### Step

cite: guide-book 48 "pads with the same number are grouped"
check: Tapping the pads in turn, only the last-tapped sound plays -- the new sound stops the previous one.

Pick two pads with sounds long enough to overlap. In `SOUND EDIT`, set both pads'
`GROUP` to the same number (for example 1). Leave `SOUND EDIT` and tap the two
pads one after the other.

### Step

cite: guide-book 48 "set 0 for no grouping"
check: With `GROUP` back at 0, the two sounds layer on top of each other instead of cutting off.

Now set both pads' `GROUP` back to 0 and tap them in turn again to compare.

### Why

Grouping is for sounds you don't want to overlap -- open and closed hi-hats,
alternate takes of a phrase, or chop slices that should silence each other.

## The COLOR item

type: quiz
id: q-5-14
cite: guide-book 49 "Sets the lighting color of the pad."
tags: leveling-up, core

What does the `COLOR` item set, and which colors do the eight values give you?

### Answer

It sets the lighting color of the pad: 1 Neon Yellow, 2 Orange, 3 Red, 4 Purple,
5 Blue, 6 Light Blue, 7 Green, 8 Light Green.

## Where the BPM value comes from

A sample's `BPM` item already shows a number you never typed in. Where did it come

It was analyzed automatically during recording. You can also set it manually.

## Excluding a sample from Beat Sync

type: quiz
id: q-5-16
cite: guide-book 49 "which excludes that sample from Beat Sync"
tags: leveling-up, stretch

In the `BPM` item, how do you exclude a sample from Beat Sync?

- [x] Long-press the left button to set the BPM to ---
- [ ] Set the BPM to 0 with the right button
- [ ] Set the sample's `GROUP` to 0
- [ ] Turn Beat Sync off in the system settings

### Why

Setting --- only opts *this sample* out of automatic beat matching; the system
setting would turn Beat Sync off for everything.

## What waveform editing changes

type: quiz
id: q-5-18
cite: guide-book 49 "change where sample playback starts and ends"
tags: leveling-up, core

What two things about a sample's playback does waveform editing let you change?

- [x] Where playback starts and where it ends (the start point and end point)
- [ ] The sample's pitch and volume
- [ ] The sample's lighting color and group
- [ ] The sequence tempo and time signature

### Why

Trimming the start and end is how you use only part of a sample -- one hit out of
a rhythm pattern, or one word out of a phrase.

## Both points at once

type: quiz
id: q-5-19
cite: guide-book 49 "You can do it with both dials at once!"
tags: leveling-up, core

You need to move both the start point and the end point. Do you have to adjust them
one at a time?

### Answer

No -- you can adjust the start and end points with both dials at once, one dial for
each point.

## Change a pad's lighting color

type: drill
id: d-5-05
cite: guide-book 49 "Sets the lighting color of the pad."
tags: leveling-up, core

Color-code one pad to match the role of its sound -- the way the preset banks do.

### Step

cite: guide-book 49 "Sets the lighting color of the pad."
check: The pad's lighting color visibly changes with each value, stepping through all eight colors.

In `SOUND EDIT` for your chosen pad, select `COLOR` and step the value from 1 to 8
with ←/→, watching the pad change color each time.

### Step

cite: guide-book 49 "Color-coding pads to match the content of their sounds makes the unit easier to use."
check: The pad stays lit in your chosen color back in Performance mode, standing out from its neighbors.

Settle on a color that matches the sound's role (for example, one color for drums,
another for phrases), then leave `SOUND EDIT`.
