## Do channel changes survive power-off
ja: ## チャンネル設定は電源オフ後も残るか

type: quiz
id: q-5-85
cite: midi 1 "Changed setting values are retained even when the power is turned off."
tags: midi, stretch

You change `MIDI OUT Ch.` from 1 to 3 and then power the unit off. What do you find
when you power it back on?
ja: `MIDI OUT Ch.` を 1 から 3 に変更し、本機の電源を切りました。次に電源を入れたとき、設定はどうなっていますか。

- [x] The channel is still 3 -- changed values are retained across power-off
ja: - [x] チャンネルは 3 のまま -- 変更した値は電源をオフしても保持されます
- [ ] The channel has reset to its default of 1

has to be configured once.
ja: チャンネル設定はほかのシステム設定と同様に記憶されるので、スタジオのセットアップは一度設定するだけで済みます。

## Transmitted vs. received note range
ja: ## 送信と受信のノートナンバー範囲

type: quiz
id: q-5-87
cite: midi 2 "See Note mapping"
tags: midi, stretch

Which note numbers does the SXC-1 transmit, and which does it receive?
ja: SXC-1 が送信するノートナンバーと受信するノートナンバーは、それぞれどの範囲ですか。

- [x] Transmits 36-99, receives 36-115
ja: - [x] 送信は 36-99、受信は 36-115
- [ ] Transmits 36-115, receives 36-99
ja: - [ ] 送信は 36-115、受信は 36-99
- [ ] Transmits and receives 0-127
ja: - [ ] 送受信とも 0-127
- [ ] Transmits and receives 36-99
ja: - [ ] 送受信とも 36-99

### Why

Reception covers 16 extra notes (100-115) because those are the receive-only
"Active" slots that always trigger the current bank's pads.
ja: 受信だけが 16 ノート（100-115）多いのは、これらが受信のみの「Active」枠で、常に選択中のバンクのパッドを鳴らすためです。

## Which CC the volume sliders use
ja: ## 音量スライダーが使う CC

type: quiz
id: q-5-88
cite: midi 3 "Changes continuously from 0 at the left end to 127 at the right end"
tags: midi, stretch

Which Control Change number does the `MAIN VOL` slider transmit and receive?
ja: `MAIN VOL` スライダーが送受信するコントロール・チェンジ番号はどれですか。

- [x] CC 7
ja: - [x] CC 7
- [ ] CC 11
ja: - [ ] CC 11
- [ ] CC 16
ja: - [ ] CC 16
- [ ] CC 80
ja: - [ ] CC 80

### Why

CC 7 is the MIDI-standard channel volume, so `MAIN VOL` maps to it; the
`INPUT VOL` slider uses CC 11 (expression) instead. Both run 0 at the left end to
127 at the right end.
ja: CC 7 は MIDI 標準のチャンネルボリュームなので、`MAIN VOL` に割り当てられています。一方、`INPUT VOL` スライダーは CC 11（エクスプレッション）を使います。どちらも左端 0 ～ 右端 127 で連続変化します。
