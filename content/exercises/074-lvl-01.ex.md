## Which firmware first supports MIDI

type: quiz
id: q-5-82
cite: midi 1 "supports MIDI IN/OUT and the transmission and reception of Control Change commands"
tags: midi, stretch

Starting from which firmware version does the unit support MIDI IN/OUT and the
transmission and reception of Control Change commands?

- [x] Ver. 1.1.1
- [ ] Ver. 1.0.0
- [ ] Ver. 1.2.0
- [ ] Ver. 1.3.0

### Why

Earlier firmware has no MIDI at all -- if the `MIDI IN Ch.` items are missing from
your system settings, update the firmware first (the User's Guide explains how).

## Where MIDI channels are set

Where do you set the unit's MIDI transmit and receive channels?

- [x] The `MIDI IN Ch.` and `MIDI OUT Ch.` items in the system settings
- [ ] The CASIO Sampler App's settings screen
- [ ] The `A`-`D` bank buttons

## Do channel changes survive power-off

type: quiz
id: q-5-85
cite: midi 1 "Changed setting values are retained even when the power is turned off."
tags: midi, stretch

You change `MIDI OUT Ch.` from 1 to 3 and then power the unit off. What do you find
when you power it back on?

- [x] The channel is still 3 -- changed values are retained across power-off
- [ ] The channel has reset to its default of 1

### Why

Channel settings are remembered like other system settings, so a studio setup only
has to be configured once.

## Transmitted vs. received note range

type: quiz
id: q-5-87
cite: midi 2 "See Note mapping"
tags: midi, stretch

Which note numbers does the SXC-1 transmit, and which does it receive?

- [x] Transmits 36-99, receives 36-115
- [ ] Transmits 36-115, receives 36-99
- [ ] Transmits and receives 0-127
- [ ] Transmits and receives 36-99

### Why

Reception covers 16 extra notes (100-115) because those are the receive-only
"Active" slots that always trigger the current bank's pads.

## Which CC the volume sliders use

type: quiz
id: q-5-88
cite: midi 3 "Changes continuously from 0 at the left end to 127 at the right end"
tags: midi, stretch

Which Control Change number does the `MAIN VOL` slider transmit and receive?

- [x] CC 7
- [ ] CC 11
- [ ] CC 16
- [ ] CC 80

### Why

CC 7 is the MIDI-standard channel volume, so `MAIN VOL` maps to it; the
`INPUT VOL` slider uses CC 11 (expression) instead. Both run 0 at the left end to
127 at the right end.

## The FX dials and button values

type: quiz
id: q-5-89
cite: midi 3 "127 when pressed, 0 when released"
tags: midi, stretch

Which CC numbers do the `FX1` and `FX2` dials use, and what values do the unit's
buttons transmit when pressed and released?

### Answer

The `FX1` dial is CC 16 and the `FX2` dial is CC 17. Buttons transmit value 127
when pressed and 0 when released.

## What the input switch transmits

type: quiz
id: q-5-90
cite: midi 3 "MIC:0, AUDIO IN:64, USB:127"
tags: midi, stretch

The `INPUT SELECT` switch transmits CC 110 (listed as INPUT SWITCH in the Control
Change list). Which value corresponds to each position?

### Answer

`MIC` transmits 0, `AUDIO IN` transmits 64, and `USB` transmits 127.
