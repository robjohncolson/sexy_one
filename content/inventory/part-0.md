# Inventory — Front matter — Safety, parts, and operation overview

Source: `translations/guide-book.md`, pages 1-11 (cover and CONTENTS, "Please note the following", "Safety precautions", "Operating precautions", "Names of parts", "Operation overview") — the material before the book's numbered parts (Preparation onward begins on p. 12). No cross-read required: the Startup Guide's overlapping setup precautions were already folded into the Part: Preparation inventory. All page citations are Guide Book pages.

## Learning objectives

1. Identify all 13 numbered callouts in the "Names of parts" diagram — display (OLED display), directional buttons, sliders, FX1/FX2 buttons/dials, function buttons, pads section, built-in microphone, bank select buttons, connector section, power switch, INPUT SELECT switch, built-in speaker, battery cover — and state each part's function (p. 10).
2. Distinguish the five connectors of the connector section (PHONE jack, LINE OUT jack, AUDIO IN jack, DATA port, POWER/DATA port) by role, and know that of the two USB ports only POWER/DATA supplies power (p. 10).
3. Map each `INPUT SELECT` switch position (`MIC` / `♪` / `USB`) to the input source it selects (p. 10).
4. Interpret the safety labels (⚠ Warning = death or serious injury; ⚠ Caution = minor injury or property damage) and the graphic symbols ("must not do" = Prohibited; "must do" = Required) used throughout the manuals (p. 3).
5. Locate — rather than memorize — the applicable safety or operating precaution (batteries, USB cable and USB power, placement and environment, cleaning, volume, straps, data backup) when a situation calls for it (pp. 2-9).
6. Apply the everyday operating practices stated in the precautions: set MAIN VOL to minimum before turning the power on or connecting headphones; use the built-in microphone at close range; distinguish the screen saver (display off after about 30 minutes) from Auto Power Off; know that USB power takes priority over installed batteries; and know that LINE OUT output does not silence the unit's speaker (pp. 7-8).
7. Navigate the Operation overview mode map: which press (short or long, and of which button) moves from Performance mode to bank selection, sequence selection, Sequence mode, REC mode, DEL mode, EDIT mode, and the system settings (p. 11).
8. Use the Operation overview function table to find the page where each function is explained (p. 11).

## Quiz/flashcard candidates

- The ⚠ Warning safety label indicates content that could result in death or serious injury (p. 3).
- The ⚠ Caution safety label indicates content that could result in minor injury or property damage (p. 3).
- The crossed-out circle symbol marks "something you must not do" (Prohibited); the filled circle symbol marks "something you must do" (Required) (p. 3).
- Panel item 1, the display (OLED display), displays various information such as waveforms and settings (p. 10).
- Panel item 2, the directional buttons, are used to select menus, change values, and so on (p. 10).
- The unit has two sliders: INPUT VOL and MAIN VOL (p. 10).
- The INPUT VOL slider adjusts the input level for recording (p. 10).
- The MAIN VOL slider adjusts the volume of the built-in speaker and headphones (p. 10).
- The FX1 and FX2 button/dial pairs are used to apply effects to sounds and to edit waveforms: the buttons switch ON/OFF, and the dials select effects and change parameters (p. 10).
- The function button row comprises six buttons: ▶/■, REC, ONE SHOT, LOOP, DEL, EDIT (p. 10).
- Function button ▶/■ is play/stop (p. 10).
- Function button REC starts/stops recording (sampling) (p. 10).
- Function button ONE SHOT toggles full-sound playback (p. 10).
- Function button LOOP toggles loop playback (p. 10).
- Function button DEL deletes sounds (p. 10).
- Function button EDIT switches editing modes (parameters / waveform editing) (p. 10).
- Pads section: a sound is assigned to each pad and pressing a pad plays it; the pads are used to play, record, and edit sounds (p. 10).
- The built-in microphone is used for recording with the unit on its own (p. 10).
- The bank select buttons (A/B/C/D) switch sound banks and sequences while performing (p. 10).
- The connector section holds five connectors: the PHONE, LINE OUT, and AUDIO IN jacks and the DATA and POWER/DATA ports (p. 10).
- The PHONE jack connects headphones (3.5 mm stereo mini) (p. 10).
- The LINE OUT jack connects to a mixer, speakers, etc. to output sound (3.5 mm stereo mini) (p. 10).
- The AUDIO IN jack connects an external device to input sound (3.5 mm stereo mini) (p. 10).
- The DATA port is a USB port for data communication with a smartphone (MIDI/audio transfer) (p. 10).
- The POWER/DATA port is a USB port for power supply and for data communication with a smartphone (MIDI/audio transfer) (p. 10).
- Of the two USB ports, only POWER/DATA supplies power; both handle data communication with a smartphone (p. 10).
- The power switch turns the unit's power ON/OFF (p. 10).
- The INPUT SELECT switch switches the input source for recording: MIC = built-in microphone, ♪ = AUDIO IN jack, USB = USB port (p. 10).
- The built-in speaker is used for playback with the unit on its own; the five-view diagram places it on the rear (p. 10; also p. 13).
- The battery cover is removed to insert batteries (p. 10).
- The MAIN VOL is shared between the headphones and the speaker, and the actual volume differs between them at the same slider position — set MAIN VOL to minimum before turning the power on or connecting headphones, and raise it gradually (p. 7).
- The built-in microphone is designed for close-range sound pickup: use it with the sound source close to the mic, and make a test recording before important recordings (p. 7).
- Screen saver function: if no operation is performed for about 30 minutes, the display turns off automatically; a button or pad operation restores it. This is different from Auto Power Off (p. 7).
- If a USB AC adaptor is connected to the POWER/DATA port while batteries are installed, USB power takes priority (p. 8).
- Even when an external speaker or similar is connected to the LINE OUT jack, sound is still output from the unit's speaker; to silence it, set MAIN VOL to minimum (p. 8).
- Performance mode is the normal mode for performing (p. 11).
- Short-pressing an A-D button leads to bank selection; long-pressing an A-D button leads to sequence selection (p. 11).
- From Performance mode, REC enters REC mode, DEL enters DEL mode, and EDIT enters EDIT mode (p. 11).
- EDIT opens EDIT mode, while long-pressing EDIT opens the system settings (p. 11).

## Cross-chapter dependencies

- This chapter is the book's entry point: it has no earlier prerequisites. Every later chapter assumes "Names of parts" (p. 10) — pads, directional buttons, function buttons, bank select buttons, dials, sliders, jacks and ports.
- Part: Preparation (pp. 12-13) applies the USB-power and battery precautions (pp. 8-9) and the volume practice (MAIN VOL to minimum before power-on or headphones, p. 7) when powering the unit and outputting sound.
- Part: Sampling (p. 28) sends readers to "Connections" (p. 8) before recording from external devices; the close-range microphone note (p. 7) underlies all mic sampling.
- Part: Leveling up: the system settings previewed on the mode map (p. 11) are detailed on p. 55 (including the BATTERY Type setting from p. 9 and APO Time); the backup precaution (p. 6) is fulfilled by the CASIO Sampler App's backup settings (p. 60).
- Operation overview (p. 11) forward-references every mode's teaching pages (pp. 15-55); its transitions are the map for the mode-entry procedures taught in Part: Pad play, Part: Sampling, Part: Sequencer, and Part: Leveling up.
